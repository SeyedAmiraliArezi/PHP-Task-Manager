# Task Manager (Demo)

A simple task management application built with PHP as a practice project.

## Run

Start the PHP development server:

```bash
php -S localhost:8000
```

Open the following URL in your browser:

http://localhost:8000

## Features

- User login and logout
- Add and delete tasks
- Task listing
- Task progress bars
- Task status badges
- Jalali (Persian) date display
- File-based data storage

## Technologies

- PHP
- HTML
- CSS

## Security Notice

This project is for educational and practice purposes only. It is not production-ready.

- Passwords are stored in plain text.
- Data is stored in files instead of a database.
- CSRF protection is not implemented.
- Rate limiting is not implemented.
- Password hashing is not implemented.

Do not use real or sensitive information with this demo.
